# Plant Pal — plan

An app for one person, with indoor plants, in Alexandria, VA. It reminds her when to water,
identifies a plant from a photo, and shows care information copied from a trusted source.

## Rules

- **No invented plant facts.** Every care fact shown in the app is copied from the
  NC State Extension Gardener Plant Toolbox profile it links to. The dataset is generated by
  `scripts/fetch-ncsu.mjs`, never typed by hand.
- If a plant is not in that dataset, the app says so and links to the NC State search. It
  does not fill the gap.
- Watering intervals are **her setting**, not a fact from the source. NC State describes
  conditions ("moist soil", "allow to dry", "reduce watering in winter") but does not give
  "every N days". The app shows the source text next to the interval she picks.

## Sources

| What | Source | Why |
|---|---|---|
| Care information (light, soil, maintenance, description, toxicity tags) | [NC State Extension Gardener Plant Toolbox](https://plants.ces.ncsu.edu/find_a_plant/?tag=houseplant), 426 houseplant profiles | University extension program, maintained by Master Gardener volunteers |
| Plant identification from a photo | [Pl@ntNet API](https://my.plantnet.org) | Scientific consortium, free tier (500 IDs/day), browser calls allowed |

Nothing is scraped at runtime; the NC State data is fetched once into `src/data/` with the
source URL for each plant, and can be refreshed with `npm run fetch-data`.

## How it works

1. **Scan** — she takes a photo. Pl@ntNet returns candidate species with a confidence score.
   She confirms the match (or picks another candidate).
2. **Match** — the app looks the scientific name up in the NC State dataset (by scientific
   name, synonyms, then genus).
3. **Plant page** — her photo, the NC State facts with a "Source" link, her watering interval,
   and the watering log.
4. **Reminders** — a "Due today" list on the home screen and an app badge. Because a
   home-screen web app cannot fire a notification at a set time on its own, each plant also
   has an **Add to Calendar** button that creates a repeating calendar event with an alert.
   (A true push-notification reminder needs a small server; see "Later".)

## Stack

- Vite + React + TypeScript, installable PWA (works on iPhone and Android, no app store)
- Data on the phone (IndexedDB via Dexie): plants, photos, watering log, settings
- Hosted free on GitHub Pages; deployed with `npm run deploy`
- Pl@ntNet API key is entered once in Settings and stays on her phone (not in the repo)
